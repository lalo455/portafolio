# Encuesta – Sistema de encuestas de satisfacción

Aplicación ASP.NET MVC (C#) con SQL Server, organizada por capas (Core, Application, Infrastructure, Web) siguiendo SOLID y DRY, con repositorios Dapper e inyección de dependencias. Las especificaciones de diseño están en `openspec/`.

## Ejecutar
Requiere .NET y SQL Server / LocalDB; ajusta `DefaultConnection` en `appsettings.json`.
