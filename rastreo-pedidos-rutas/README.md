# Rastreo – Asignación y seguimiento de rutas y pedidos (ASP.NET MVC + SAP B1)

Aplicación web ASP.NET MVC 5 (C#, AngularJS, jQuery) para la **gestión logística de entregas**: asignación de pedidos a rutas, seguimiento de la entrega, cotizaciones/pedidos, corte de caja, impresión de tickets (Crystal Reports) y generación de PDF con jsPDF. Se integra con **SAP Business One** (DI API/SQL). Más detalle en `Rastreo/docs/` (arquitectura y soporte).

> **Versión de portafolio (saneada).** Se eliminaron credenciales, servidores, nombres de clientes y de la empresa, razones sociales, direcciones, teléfonos, logotipos, reportes `.rpt` y compilados. Configura tus propios valores `YOUR_*` en `Web.config` / `ConexionController`. No incluye datos reales.
