# WMS web integrado con SAP Business One

Sistema de administración de almacén (ASP.NET MVC, Dapper, JavaScript) integrado con **SAP Business One** mediante DI API: recepciones, traspasos, surtido, entregas, producción, impresión de etiquetas y recuento. Incluye una capa `Logic` por dominio y vistas Razor con scripts por módulo.

> **Versión de portafolio (saneada).** Credenciales, servidores, bases de datos, rutas, códigos de almacén y nombres de clientes/empresa fueron reemplazados por valores genéricos; se removieron logos, reportes `.rpt` y librerías propietarias. Configura `Web.config` con tus propios valores.
