# WMS Móvil (.NET MAUI)

App móvil de almacén para terminales de mano: login, menú, escaneo (código de barras/RFID mediante `ScannerOrchestrator`) y traspasos contra una API REST (`ApiService`). Arquitectura MVVM, localización (es/en) y servicio de audio para alertas.

> Versión de portafolio: la URL de la API y el identificador de tenant son valores de ejemplo (`ApiService.cs`). Las librerías propietarias del fabricante del lector RFID no se incluyen.
